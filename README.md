# 🌾 KrishiRakshak AI

## AI-Powered Predictive Farm Risk & Decision Support System

KrishiRakshak AI is an AI-assisted agricultural decision-support
platform designed to help farmers identify potential agricultural
risks and compare possible actions before making decisions.

## 🎯 Key Features

- 🌱 Crop health analysis
- 🌦️ Weather-based risk analysis
- 💧 Soil/moisture monitoring
- 🛰️ Satellite/GIS integration
- 🚨 Early risk alerts
- 🧠 AI-assisted recommendations
- 🔥 What-If decision simulator

## 🏗️ Technology Stack

- React
- Python
- FastAPI
- Scikit-learn
- TensorFlow/PyTorch
- PostgreSQL/Firebase
- Leaflet/OpenStreetMap
